# Contributor Covenant Code of Conduct

This project and everyone participating in it is governed by the Contributor Covenant Code of Conduct. By participating, you are expected to uphold this code.

The full text is available at: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Summary of expectations:

- Be respectful and kind to others.
- Do not harass, belittle, or discriminate against contributors.
- Respect differences of opinion and work collaboratively.
- Report unacceptable behavior to the repository maintainers.

Enforcement:

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported by contacting the project maintainers at the repository's security contact or by opening an issue marked private if your GitHub plan supports it. All reports will be reviewed and investigated and will result in a response that is deemed necessary and appropriate to the circumstances.


For full details, refer to the Contributor Covenant: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
