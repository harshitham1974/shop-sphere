# Contributing to Shop Sphere

Thanks for your interest! Contributions are welcome from everyone. Please follow these steps:

1. Fork the repository and create a feature branch:
   - git checkout -b feat/short-description

2. Keep commits focused and well-named. Use conventional commits if possible:
   - feat: add payment integration
   - fix: correct cart total calculation
   - docs: update README

3. Write tests for new features and ensure all tests pass:
   - mvn test or ./gradlew test

4. Open a pull request with a clear description of changes and testing steps.

5. Ensure CI passes before requesting review.

Coding conventions:
- Java 17
- Use meaningful names and Javadoc for public APIs
- Keep methods short and single-purpose

If you plan larger changes (architecture/core design), open an issue first to discuss.
